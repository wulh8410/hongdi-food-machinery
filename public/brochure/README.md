## 导出 PDF

在浏览器打开画册后：

1. 按 `Ctrl + P`
2. 选择“另存为 PDF”
3. 纸张选择 `A4`
4. 方向选择“横向”
5. 边距选择“无”或“最小”
6. 背景图形选择“打印背景图形”
7. 保存 PDF
